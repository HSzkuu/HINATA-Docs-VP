# 模拟卡片

HINATA Go 可以把已保存的卡片交给 HINATA 读卡器模拟：模拟期间读卡器不再读卡，而是作为一张卡应答，让手机、游戏或其他读卡设备读到与原卡一致的信息。

::: tip 适用场景
* **NDEF 数据集**：用手机贴近读卡器即可打开其中的网址、文本等内容，不必再准备实体标签。
* **FeliCa 卡 / Amusement IC**：让读卡设备读到与原卡相同的卡号，需要时还能读到卡上保存的区块数据，用于测试或验证。
:::

::: warning ⚠️ 模拟的卡片无法用于官方服务器
模拟只还原卡片上已保存的信息，不包含需要认证才能读取的内容，也无法代替官方卡片在官方网络中使用。
:::

## 模拟后可以做什么

| 模拟的卡片 | 能做什么 | 读不到什么 |
| :--- | :--- | :--- |
| NDEF 数据集 | 手机贴近读卡器就能打开数据集里的网址、读取其中的文本，不必再准备实体标签。标签是只读的，手机无法向它写入 | 无（整条数据集都会完整呈现） |
| FeliCa 卡（含 Suica、PASMO 等交通卡） | 读卡设备能读到与原卡相同的卡号，还能读到卡片保存下来的区块，例如余额和交易记录 | 需要认证才能读取的区块；卡片读取时没有保存下来的区块会读出全 0 |
| Amusement IC | 读卡设备能读到与原卡相同的卡号（Access Code）和卡片保存下来的区块，和刷原卡的结果一致 | 需要认证才能读取的区块；没有保存下来的区块会读出全 0 |

模拟还原的是**读取卡片时保存下来的数据**。想让它更接近真卡，刷卡时请保持卡片贴近直到读取完成——卡片移开得早，后面那些区块就会缺失，模拟出来是空的。

## 支持的卡片类型

* **NDEF 数据集**：可新建，也可由扫描到的实体标签保存而来；内容为空或过大的数据集无法模拟。
* **FeliCa 卡**：任意 FeliCa 卡片，包括 Suica、PASMO 等交通卡。保存时需要有完整的卡号信息。
* **Amusement IC**：需要保存过完整的 Access Code 才能模拟。

::: info 说明
旧式 Aime 卡、交通联合卡、NESiCA 卡等目前无法模拟。
:::

NDEF 数据集可在 **卡片** 页面的添加菜单中通过 **新建 NDEF 数据集** 创建，扫描到的实体标签保存后同样可以模拟。

::: tip 用 iPhone 读取模拟的 NDEF 数据集
iPhone 在后台读取时主要处理网址，文本等其他内容需要用 NFC 应用读取。
:::

## 前置条件

| 条件 | 说明 |
| :--- | :--- |
| 读卡器 | 需要连接一台 HINATA / HINATA Lite 读卡器（USB，或网页版的 WebHID） |
| 平台 | iOS 不提供（无法驱动读卡器）；Android 版 HINATA Go 与网页版（WebHID）可用 |
| 固件 | 需要支持模拟功能的读卡器固件，旧固件会在开始后提示模拟失败，请先[更新固件](/update/) |
| 卡片 | 必须是一张**已保存**的卡片，且属于上方支持的类型 |
| 版本 | HINATA Go 2.8.0 及以上 |

## 操作步骤

### 第一步：连接读卡器

在 HINATA Go 中连接 HINATA 读卡器，并确认设备状态显示为已连接。模拟完全由读卡器完成，手机自身的 NFC 不参与。Windows / macOS / Linux 上请使用[网页版](https://go.neri.moe)，Android 上使用 App。

### 第二步：打开卡片详情

切换到 **卡片** 栏目，点开要模拟的已保存卡片。模拟入口只出现在已保存卡片的详情页。

### 第三步：点击模拟

在底部操作栏点击 **模拟** 按钮（contactless 图标）。该操作栏同时显示保存、写入、发送等按钮，按钮较多时会自动分为两行。

弹出的对话框标题为 **模拟 NDEF 标签**（NDEF 数据集）或 **模拟卡片**（FeliCa 卡、Amusement IC）。

### 第四步：让读卡设备读取

对话框会先显示「正在准备读卡器」，随后：

* NDEF 数据集：显示「请将手机靠近读卡器」，手机连接后显示「手机已连接，正在读取」。
* FeliCa 卡 / Amusement IC：显示「等待读卡设备读取」，读卡设备开始读取后显示「读卡设备正在读取」。

此时将手机或其他读卡设备贴近 HINATA 读卡器即可。

* 模拟期间读卡器会暂停原本的读卡功能，停止后自动恢复。
* 卡片被读取后，对话框会显示已被读取的次数；如果读卡设备只读取卡号，这里不会显示读取状态。
* 模拟会一直保持，直到点击 **停止模拟**。

### 第五步：停止模拟

点击 **停止模拟**（停止过程中显示「正在停止」），待按钮变为 **完成** 后点击关闭对话框。模拟期间对话框不会被误触关闭，返回操作等同于停止模拟。

## 模拟不完整的卡片

对话框里有两种警告，说明模拟出来的卡片和真卡会有差距：

* **该卡片未完整读取，模拟不完整：未读取的区块会返回全 0** —— 卡片读取时没有保存齐全，缺失的区块会读成全 0。重新刷卡并保持卡片贴近直到读取完成，就能补上。
* **无法响应读卡设备的挑战（MAC、MAC_A），需要验证卡片的读卡设备会拒绝它** —— FeliCa Lite / Lite-S 卡片（含 Amusement IC）的 MAC 无法伪造，遇到会校验 MAC 的读卡设备会被拒绝。

## 常见问题排查

| 提示 | 处理 |
| :--- | :--- |
| 模拟需要连接 HINATA 读卡器 | 当前没有连接读卡器，或连接已断开；重新连接后再次进入卡片详情 |
| 该卡片无法模拟 | 这类卡片不支持模拟（见上方说明），或卡片信息保存不完整 |
| 该数据集无法模拟 | 数据集是空的，或内容过大 |
| 该卡片未完整读取，模拟不完整：未读取的区块会返回全 0 | 重新刷卡，保持卡片贴近读卡器直到读取完成，区块才会保存完整 |
| 无法响应读卡设备的挑战（MAC、MAC_A），需要验证卡片的读卡设备会拒绝它 | 这是 Lite / Lite-S 卡片的固有限制，出现在模拟对话框里属于正常提示；需要校验 MAC 的读卡设备无法使用模拟卡 |
| 读卡器已断开 | 模拟随读卡器断开而结束，重新插拔读卡器后再次开始 |
| 模拟失败，请确认读卡器固件支持模拟功能 | 读卡器固件不支持模拟，请[更新固件](/update/)后重试 |
